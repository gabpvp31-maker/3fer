# Código do Red Rocket

Esta pasta permite consultar a autoria Blender, o exportador e o motor web. Os recursos completos (modelo Blender, texturas e GLB) estão no ZIP `red-rocket-fontes.zip` na raiz desta branch. Extraia esse ZIP para reconstruir ou executar o projeto; os arquivos de código isolados não contêm esses recursos.

O ZIP `red-rocket-jogavel.zip` abre offline após extrair e abrir `index.html`. O projeto é uma recriação de fã com geometria autoral e texturas CC0, sem assets extraídos de Fallout.
